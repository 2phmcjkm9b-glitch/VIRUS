Это журнал состояния разработки для версии VIRUS v6. Исходный RAR в папке `Игра/` не менялся.

## Содержимое v6
- 8 игровых зон.
- Прогрессия стартового числа врагов: 20, 30, 40, 50, 60, 70, 80, 90 (боссы входят в значения, указанные для зон 4 и 8).
- Квоты ДНК: 14, 25, 36, 47, 58, 69, 80, 91.
- Интервалы подкреплений: 7, 6.5, 6, 5.5, 5, 4.5, 4, 3.5 секунды.
- Выбор только пройденных уровней; непройденные уровни закрыты.
- Сохранение прогресса и лучшего набора мутаций зоны.
- Карта эволюции и финальная сцена победы.
- Исправлено автоматическое закрытие окна описания уровня: окно закрывается только по явному действию игрока.

## Проверки, заявленные для локального архива v6
- 24 регрессионных теста прошли.
- 4 000 сгенерированных миров проверены.
- TypeScript/TSX синтаксически проверен.
- Полная production-сборка и запуск в браузере не подтверждены из-за проблем установки зависимостей в проверочной среде.
